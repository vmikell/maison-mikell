# Maison Growth Tools and Access List

Prepared: 2026-04-24

## Goal

List the minimum tools, accounts, and access needed for Signal to run Maison growth well.

This is organized by:
- must-have now
- should-have soon
- nice-to-have later

---

# Must-have now

## 1. Social accounts

### Instagram account for Maison
Needed for:
- reels
- carousels
- stories
- audience testing
- DMs if needed later

### TikTok account for Maison
Needed for:
- short-form discovery
- message testing
- fast hook validation

### X account for Maison or founder-led Maison posting
Needed for:
- founder voice
- testing positioning in public
- joining adjacent conversations
- sharp short-form message testing

## 2. Account access

Need the ability to:
- log in
- draft posts
- publish posts
- save drafts
- read comments/replies
- read basic analytics

If direct access is not comfortable yet, an acceptable temporary setup is:
- Victor owns accounts
- Signal prepares final assets/copy
- Victor publishes manually

## 3. Landing page / signup destination

Need one live place to send people.
That means access to:
- Maison site / landing page repo
- deployment path if needed
- waitlist or signup form destination
- whatever email capture or onboarding destination is actually active

Without this, content can create interest but not capture it cleanly.

## 4. Analytics visibility

Need access to at least:
- Instagram insights
- TikTok analytics
- X analytics if used
- landing page traffic basics
- signup counts

Minimum viable answers needed each week:
- what got the most saves/shares/comments
- what drove profile visits
- what drove site visits
- what drove actual signups

## 5. Content production inputs

Need a lightweight source library of:
- Maison logo / wordmark files
- approved colors
- approved screenshots/mockups
- app UI captures
- household/lifestyle visual references
- any approved founder photos/videos if face-led content is part of the strategy

## 6. File organization

Need one clear location for:
- post drafts
- approved captions
- content calendar
- exports
- brand direction references
- screenshots / mockups

Could be:
- workspace folders
- Google Drive
- Notion
- another simple shared location

The important thing is not the tool. It is avoiding scattered assets.

---

# Should-have soon

## 7. Scheduling / drafting tool

Helpful options:
- native Meta scheduling for Instagram
- TikTok drafts/native scheduler
- a scheduler like Buffer/Later/Metricool if desired

This is not critical on day one, but it helps once publishing gets regular.

## 8. Comment / community workflow

Need a simple plan for:
- who replies
- how fast replies should happen
- when to engage vs stay quiet
- what tone to use

If Signal is helping heavily here, comment access matters.

## 9. Lightweight analytics sheet or dashboard

Could be simple.
Track:
- post date
- platform
- format
- hook
- saves
- shares
- comments
- profile visits
- landing-page visits
- signups
- notes on why it worked or didn’t

## 10. Basic brand kit

Need an approved small kit that includes:
- wordmark
- color palette
- typography direction
- visual rules for posts
- example posts to emulate

This prevents drift as content volume increases.

---

# Nice-to-have later

## 11. Video editing workflow

Useful tools could include:
- CapCut
- Final Cut Pro
- Premiere
- simple mobile editing path

Not required if early content is intentionally light and human.

## 12. Social listening / research workflow

Helpful for:
- finding adjacent conversations
- spotting language people already use
- identifying creators or communities to watch

## 13. Creator / micro-influencer outreach setup

Only useful once the message is clearer.
Would need:
- outreach list
- DM/email templates
- tracking sheet

## 14. Better visual generation / design support

This matters because stronger visuals make all organic posts easier.
Useful upgrades:
- reliable image generation/editing
- faster mockup generation
- easier screenshot packaging
- cleaner export tools

---

# Access model recommendation

Recommended near-term setup:

## Option A — controlled access
Victor retains ownership of accounts and grants Signal access where comfortable.

Best if:
- Victor wants oversight
- publishing is collaborative at first

## Option B — draft-first workflow
Signal prepares:
- captions
- visuals guidance
- content calendar
- response guidance

Victor publishes manually.

Best if:
- account setup is still early
- trust/access is still being phased in

## Option C — fuller operating access later
Once the workflow is stable, Signal can help run more of:
- posting
- drafting
- analytics review
- comment triage
- messaging iteration

---

# What matters most immediately

If only a few things get set up first, prioritize these:

1. Instagram account
2. TikTok account
3. landing page / signup destination
4. access to basic analytics
5. approved visual asset folder

That is the minimum stack needed to start a real grassroots loop.

---

# Bottom line

The goal is not to collect tools.
The goal is to give Signal enough access and infrastructure to:
- publish consistently
- learn from the audience quickly
- refine Maison’s message in public
- turn attention into actual signups

Without that stack, growth stays theoretical.
With it, we can start building real momentum.
